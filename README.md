# Code_BS
Non-thermal emission model for bow shocks. Two versions of the model are available: i) a one-zone model which is more approximated and runs faster, and ii) an extended model, which is more detailed and time-consuming. The details of the model is detailed in del Palacio, S., et al. 2018, A&A, 617, A13 (arxiv link: https://arxiv.org/pdf/1806.10863.pdf). The code is written as modules of Fortran90, articulated by a *Main* program, compiled using *Make* (simply run `make` in the terminal), and run as `./run.x`. The compilation with make by default makes use of the *blas* and *lapack* libraries.
Some further details of each code are given below.


## One-Zone

**Makefile**: instructions for compiling using *make*

**Makefile.depend**: details which modules depend on which other modules (needed for compilation)

**constants.f90**: useful physical and numerical constants. It is imported by **global.f90** to be used by all other modules as well.

**system_parameters.f90**: parameters of the specific system being studied. It is imported by **global.f90** to be used by all other modules as well.

**global.f90**: constants, variables and number of points in the simulation to be used by all other modules.

**controles.f90**: this sets which modules are going to run in the simulation by setting variables to *.True.* or *.False.*.

**diste.f90**: calculates the non-thermal electron population and saves it in a plain text file.

**distp.f90**: calculates the non-thermal proton population and saves it in a plain text file.

**rad(XX).f90**: calculates the SED by the respective process reading the corresponding non-thermal particle population from the file generated by **dist(X).f90**.


## Extended

**Makefile**: instructions for compiling using *make*

**Makefile.depend**: details which modules depend on which other modules (needed for compilation)

**constants.f90**: useful physical and numerical constants. It is imported by **global.f90** to be used by all other modules as well.

**system_parameters.f90**: parameters of the specific system being studied. It is imported by **global.f90** to be used by all other modules as well.

**global.f90**: constants, variables and number of points in the simulation to be used by all other modules.

**controles.f90**: this sets which modules are going to run in the simulation by setting variables to *.True.* or *.False.*.

**CD.f90**: calculates the position of the contact discontinuity (CD). The extended emitter is assumed to be made up of emission cells at these same positions (note: can be used for both shocks, FS and RS). 

**CD_rot.f90**: rotates the CD to simulate a 3-D emitter. 

**CD_termo.f90**: calculates the thermodynamical quantities at each position along the CD.

**CD_diste.f90**: calculates the non-thermal electron population at each position of the CD and saves it in a plain text file.

**CD_distp.f90**: calculates the non-thermal proton population at each position of the CD and saves it in a plain text file.

**CD_rad(XX).f90**: calculates the SED by the respective process reading the corresponding non-thermal particle population from the file generated by **dist(X).f90**.

**CD_abssyn.f90**: calculates the absorbed radio SED from a linear emitter and projects its emision at some particular frequencies in the plane of the sky, generating the input for making synthetic maps. Takes as an input the intrinsic synchrotron SED obtained with **CD_radsyn.f90**.

**SW_conv.f90**: convolves the emission map with the instrumental (synthesized) beam to compare with the observed maps. Takes as an input the emission maps obtained with **CD_abssyn.f90**.
